# ระบบบันทึกผลการปฏิบัติงาน P4P (Family Medicine)
**กลุ่มงานเวชกรรมสังคม โรงพยาบาลนราธิวาสราชนครินทร์**

เว็บแอปพลิเคชันสำหรับแพทย์และบุคลากรทางการแพทย์ ในการบันทึกกิจกรรมและคำนวณแต้ม P4P (Pay for Performance) ประจำวันและประจำเดือน สอดคล้องกับแบบฟอร์มมาตรฐานของกลุ่มงานเวชกรรมสังคม

---

## 🌟 จุดเด่น

- **ไม่ต้องติดตั้ง ใช้งานได้ทันที**: เปิดผ่านเบราว์เซอร์ได้ทั้งบนคอมพิวเตอร์ แท็บเล็ต และสมาร์ทโฟน
- **ซิงก์อัตโนมัติ (Auto Save to Sheet) — เปิดใช้เป็นค่าเริ่มต้น**: ไม่ต้องกดอะไรเลย แก้ข้อมูลเมื่อไรระบบส่งขึ้น Google Sheet ให้เองหลังหยุดพิมพ์ ~3 วินาที พร้อมป้ายสถานะ "✓ ซิงก์แล้ว" บนหัวหน้า — หรือกดปุ่ม "บันทึกเข้าชีต" ส่งทันทีก็ได้ (ปิดสวิตช์ได้ในแท็บ "ส่งออกข้อมูล")
- **สร้างแท็บให้อัตโนมัติ**: ลงทะเบียนชื่อในเว็บครั้งเดียว ระบบสร้างแท็บของแต่ละคนจากต้นแบบ `Sheet1` ให้ทันที (และสร้างแท็บใหม่ให้เองทุกเดือน) แล้วเขียนข้อมูลลง G6:AK25 ตรงจุด — ผู้ใช้ไม่ต้องเข้าไปสร้างแท็บในชีตเองเลย
- **พิมพ์/ส่งออกได้เหมือนชีต**: แท็บ "ตาราง 31 วัน" มีหัวเรื่อง 3 บรรทัดเหมือนแถว A1–A3 ของชีต พร้อมปุ่มพิมพ์เป็น PDF (แนวนอน A4) และดาวน์โหลด Excel
- **รองรับการทำงานออฟไลน์**: ข้อมูลบันทึกในเบราว์เซอร์ (Local Storage) ของแต่ละคน ไม่สูญหายเมื่อปิดหน้าเว็บ — ถ้าเน็ตหลุด ระบบลองส่งใหม่เองทุก 30 วินาที (สูงสุด 5 ครั้ง) และส่งทันทีเมื่อกลับมาใช้หน้าจอ
- **ยังมีทางสำรอง**: ปุ่มคัดลอก 20 แถว × 31 วัน ไปวางที่ G6 เองได้เสมอ แม้ยังไม่ตั้งค่า Apps Script
- **ปฏิทินซิงก์วันหยุดราชการไทย**: เปิดมาที่เดือนปัจจุบันอัตโนมัติ วันแรกของเดือนตรงกับวันในสัปดาห์จริง (จ.–อา.) วันหยุดราชการขึ้นป้ายแดงทั้งในปฏิทินรายวัน ตาราง 31 วัน และสรุปรายการวันหยุดประจำเดือน

## 📅 ปฏิทินและวันหยุดราชการไทย

- **เปิดที่เดือนปัจจุบันเสมอ**: หน้าเว็บเริ่มที่เดือน/ปี พ.ศ. ของวันนี้ และเลือกวันนี้ให้อัตโนมัติ (ถ้าเคยบันทึกเดือนที่เก่ากว่า 3 เดือน ระบบจะรีเซ็ตกลับมาที่เดือนปัจจุบัน)
- **วันในสัปดาห์**: หัวตารางเป็น อา. จ. อ. พ. พฤ. ศ. ส. และวันแรกของเดือนถูกจัดให้ตรงช่องวันจริง (เช่น 1 ธ.ค. 2569 เป็นวันอังคาร → เว้น 2 ช่องแรก)
- **สีประจำวัน**: อาทิตย์พื้นแดงอ่อน · เสาร์พื้นม่วงอ่อน · วันหยุดราชการพื้นแดงเข้มกว่าพร้อมจุดแดงมุมขวา (วันหยุดมีความสำคัญเหนือสีเสาร์–อาทิตย์)
- **แสดงผล 3 จุด**: (1) ช่องวันที่ในปฏิทินรายวัน (2) ป้ายชื่อวันหยุดใต้หัวข้อ "บันทึกผลงาน วันที่ …" (3) กล่อง "🇹🇭 วันหยุดราชการเดือนนี้" ในแถบด้านซ้าย และหัวคอลัมน์ในตาราง 31 วันก็มีตัวย่อวัน (อ. พ. พฤ. …) กำกับ
- **ขอบเขตข้อมูล**: นับเฉพาะวันหยุดราชการตามประกาศทางการ — วันหยุดนักขัตฤกษ์ วันหยุดชดเชย และวันหยุดกรณีพิเศษที่ ครม. อนุมัติ ไม่รวมวันสำคัญทางวัฒนธรรมที่ไม่ได้หยุด (วาเลนไทน์ ตรุษจีน คริสต์มาส)

### การดูแลชุดข้อมูล `THAI_HOLIDAYS`

ข้อมูลอยู่ในตัวแปร `THAI_HOLIDAYS` ในไฟล์ `index.html` รูปแบบคีย์ `"ปีพ.ศ.-เดือน-วัน": "ชื่อวันหยุด"`

```javascript
var THAI_HOLIDAYS = {
  "2569-12-5": "วันคล้ายวันพระบรมราชสมภพ ร.9 และวันพ่อแห่งชาติ",
  "2569-12-7": "วันหยุดชดเชยวันพ่อแห่งชาติ",
  // ...
};
```

ปัจจุบันครอบคลุมปี พ.ศ. 2567–2571 โดยดึงจากปฏิทินสาธารณะของ Google (`th.th#holiday@group.v.calendar.google.com`)

> ⚠️ **สิ่งที่ต้องตรวจทุกปี**: วันหยุดประเภท**จันทรคติ** (มาฆบูชา วิสาขบูชา อาสาฬหบูชา เข้าพรรษา ออกพรรษา ลอยกระทง) และ**วันหยุดชดเชย** ที่ ครม. ประกาศเป็นรายปี จะคลาดเคลื่อนจากวันที่คำนวณล่วงหน้าได้ — เมื่อราชกิจจานุเบกษาประกาศปฏิทินวันหยุดปีถัดไป ให้เพิ่ม/แก้คีย์ใน `THAI_HOLIDAYS` แล้ว push ขึ้น GitHub Pages ใหม่ (ปี 2571 เป็นปีสุดท้ายที่มีข้อมูลล่วงหน้า ควรอัปเดตภายในปลายปี 2570)

## ☁️ การซิงก์เข้าชีตอัตโนมัติ (Google Apps Script)

ผู้ดูแลกลุ่มงานตั้งค่าครั้งเดียว ใช้ได้ทั้งทีม:

1. เปิดชีต → **ส่วนขยาย (Extensions)** → **Apps Script**
2. ลบโค้ดเดิม แล้ววางเนื้อหาไฟล์ [`Code.gs`](Code.gs) (หรือกดปุ่ม "คัดลอกโค้ด Google Apps Script" ในแท็บ **ส่งออกข้อมูล** ของเว็บแอป)
3. **ทำให้ใช้งานได้ (Deploy)** → **การทำให้ใช้งานได้รายการใหม่** → ไอคอนเฟือง → **เว็บแอป**
4. ดำเนินการในฐานะ **ฉัน** · ใครมีสิทธิ์เข้าถึง **ทุกคน** (จำเป็น)
5. คัดลอก URL ที่ลงท้ายด้วย `/exec` มากรอกในช่อง **"URL เว็บแอป Google Apps Script"** ของเว็บแอป

> 💡 **ทีมใช้งานแบบไม่ต้องตั้งค่าเลย**: เมื่อผู้ดูแลได้ URL `/exec` แล้ว ให้วางไว้ในค่าคงที่ `DEFAULT_GAS_URL` (ในไฟล์ `index.html` ใกล้บรรทัด `STORAGE_KEY`) แล้ว push ขึ้น GitHub Pages — ทีมทุกคนจะได้ URL และมีซิงก์อัตโนมัติทันทีที่เปิดเว็บ โดยไม่ต้องกรอกอะไร (ผู้ใช้ที่กรอก URL ของตัวเองไว้แล้วจะยังใช้ของตัวเอง)

จากนั้นผู้ใช้แต่ละคนเพียงกรอก **"ชื่อแท็บในชีตของฉัน"** ของตัวเอง (เฉพาะชื่อ — เช่น `นพ.ฮัมดี`) แล้วเลือกวิธีส่งข้อมูล:

| วิธี | ทำอะไร |
| --- | --- |
| **ซิงก์อัตโนมัติ** (ค่าเริ่มต้นเปิดอยู่, สวิตช์ในแท็บ "ส่งออกข้อมูล") | แก้ข้อมูลเสร็จ ~3 วินาที ส่งขึ้นชีตเองทุกครั้ง ไม่ต้องกดปุ่ม |
| **บันทึกเข้าชีต** (ปุ่มมุมขวาบน) | ส่งเดือนที่กำลังดูอยู่ขึ้นชีตทันที |

### 🏷️ ชื่อแท็บต่อท้ายเดือนอัตโนมัติ (1 เดือน = 1 แท็บ)

ระบบจะต่อท้ายชื่อแท็บที่กรอกด้วยเดือน/ปีของข้อมูลที่บันทึกให้อัตโนมัติ — ไม่ต้องพิมพ์เองทุกเดือน และข้อมูลคนละเดือนไม่ทับกัน:

- พิมพ์ชื่อแท็บไว้ `นพ.ฮัมดี` → ดูเดือน ต.ค. 2569 อยู่ → ระบบเขียนลงแท็บ **`นพ.ฮัมดี · ต.ค. 2569`**
- สลับไปดู พ.ย. 2569 → ระบบเขียนลงแท็บ **`นพ.ฮัมดี · พ.ย. 2569`** (สร้างแท็บใหม่จากต้นแบบ `Sheet1` ให้อัตโนมัติเมื่อส่งครั้งแรก)
- ใต้ช่องกรอกชื่อแท็บมีตัวแสดงตัวอย่าง "แท็บที่จะเขียนในชีต: …" และ tooltip ของปุ่ม "บันทึกเข้าชีต" ก็บอกชื่อแท็บเต็มเช่นกัน
- ถ้าเคยพิมพ์ชื่อที่มีเดือนต่อท้ายไว้แล้ว (เช่น `นพ.ฮัมดี · ต.ค. 2569`) ระบบจะตัดเดือนเก่าออกเอง แล้วต่อเดือนปัจจุบันให้ใหม่ — ชื่อจะไม่ซ้อนกัน
- สลับเดือนระหว่างที่ซิงก์อัตโนมัติกำลังรอส่ง (debounce 3 วินาที) ระบบจะเร่งส่งข้อมูลเดือนเดิมให้เสร็จก่อน แล้วค่อยเปลี่ยนเดือน — ข้อมูลไม่ตกค้างผิดแท็บ

ทั้งสองวิธีสร้างแท็บจากต้นแบบ `Sheet1` ให้อัตโนมัติพร้อมชื่อและเดือนที่ถูกต้อง

> ตั้ง `OPTIONAL_SECRET = "รหัสของคุณ"` ใน `Code.gs` เพื่อบังคับให้กรอกรหัสก่อนบันทึกได้ (แนะนำ)

### 🆕 ลงทะเบียนผู้ใช้ใหม่ → สร้างแท็บให้อัตโนมัติ (ไม่ต้องเข้าชีตเอง)

เปิดเว็บแอปครั้งแรกบนเครื่อง/เบราว์เซอร์ใหม่ ระบบจะเด้งฟอร์ม **"ลงทะเบียนผู้ใช้ใหม่"** ขึ้นมาให้เอง:

1. กรอก **ชื่อ - สกุล** (+ ตำแหน่ง/กลุ่มงาน ถ้าต้องการ) แล้วกด **"🚀 บันทึก และสร้างแท็บของฉันในชีต"**
2. ระบบสร้างแท็บ `ชื่อของคุณ · เดือน ปี` ใน Google Sheet กลาง **ทันที** (จากต้นแบบ `Sheet1` พร้อมสูตรครบ) — ผู้ใช้ไม่ต้องเปิด Google Sheet สร้างแท็บเองเลย
3. จากนั้นทุกการบันทึกผลงานจะลงแท็บของตัวเองโดยอัตโนมัติ (เดือนใหม่ = แท็บใหม่อัตโนมัติตามหัวข้อด้านบน)

ข้อควรรู้:

- ถ้ายังไม่ลงทะเบียน (ไม่มีชื่อ) ระบบจะ**ไม่ส่งข้อมูลขึ้นชีต** — ป้ายสถานะจะขึ้น `⚠ ยังไม่ลงทะเบียน` ป้องกันการเขียนทับแท็บของคนอื่นโดยไม่ตั้งใจ
- เครื่องที่ใช้งานมาก่อนหน้านี้แล้ว (มีชื่อบันทึกในเครื่องอยู่) จะไม่ถูกเด้งฟอร์มซ้ำ — แก้ไขชื่อได้ตลอดผ่านปุ่มชื่อมุมขวาบน
- กด "ยังไม่ต้องการ ใช้ในเครื่องก่อน" เพื่อข้ามได้ (บันทึกในเครื่องอย่างเดียว ไม่มีการส่งชีตจนกว่าจะลงทะเบียน)

**ป้ายสถานะบนหัวหน้า:** `⟳ รอส่ง…` → `⟳ กำลังส่ง…` → `✓ 19:24` (เวลาที่ซิงก์ล่าสุด) · หากส่งไม่สำเร็จจะขึ้น `⚠ ลองใหม่…n` และลองส่งใหม่เองทุก 30 วินาที — ข้อมูลในเครื่องไม่หาย

## 🖨️ หัวเรื่องเหมือนชีต + ส่งออก PDF / Excel จากแท็บ "ตาราง 31 วัน"

เหนือตารางรวม 31 วันมี**หัวเรื่อง 3 บรรทัดแบบเดียวกับแถว 1–3 ของ Google Sheet** เปลี่ยนตามเดือน/ผู้บันทึกอัตโนมัติ:

```
แบบบันทึกผลการปฏิบัติงาน
ประจำเดือน กุมภาพันธ์ 2569
ชื่อ - สกุล  นพ.ฮัมดี หะยีอาลี   ตำแหน่ง   นายแพทย์ชำนาญการพิเศษ กลุ่มงาน เวชกรรมสังคม
```

ปุ่มในแถบเครื่องมือของแท็บนี้:

| ปุ่ม | ทำอะไร |
| --- | --- |
| **🖨️ พิมพ์ / บันทึก PDF** | เปิดหน้าต่างพิมพ์ — เลือก "Save as PDF" ได้กระดาษแนวนอน A4 รวมหัวเรื่อง 3 บรรทัด + ตารางครบ 20 กิจกรรม × 31 วัน ซ่อนเมนู/ปุ่ม/การ์ดสรุปออกหมด (เหลือเฉพาะชีต) · คอลัมน์วันหยุด/เสาร์–อาทิตย์ พิมพ์พื้นสีเหมือนหน้าเว็บ และคอลัมน์ "รวมแต้ม" ไฮไลต์สีเขียวมิ้นต์ให้เด่นชัด |
| **📊 ดาวน์โหลด Excel** | ได้ไฟล์ `.xls` แถวแรก 3 แถวเป็นหัวเรื่องเหมือนในชีต ตามด้วยตาราง 20 แถว + แถวรวมทั้งหมด — เปิดใน Excel/Google Sheet ได้เลย |
| **คัดลอกไปวางในชีต** | เหมือนเดิม — คัดลอก 20×31 ไปวางที่ G6 |

## 📋 คำแนะนำการใช้งานร่วมกันในไฟล์ Google Sheet เดียวกัน

บุคลากรทุกคนสามารถใช้ไฟล์ Google Sheet เดียวกันได้ โดยใช้วิธี **"1 คน = 1 แท็บ (Tab) ต่อ 1 เดือน"** — **ถ้าใช้ Apps Script ไม่ต้องทำอะไรเองเลย** แค่ลงทะเบียนชื่อในเว็บแอป (หัวข้อ 🆕 ด้านบน) ระบบสร้างแท็บพร้อมต่อท้ายเดือนให้อัตโนมัติ ข้ามขั้นตอนด้านล่างได้ทั้งหมด (เก็บไว้เป็นทางสำรองเผื่อใช้แบบ manual เท่านั้น):

### ขั้นตอนสำหรับผู้ใช้ใหม่แบบ manual (เฉพาะเมื่อไม่ได้ใช้ Apps Script)
1. เปิดไฟล์ Google Sheet กลางของกลุ่มงานเวชกรรมสังคม
2. กดปุ่ม `+` มุมซ้ายล่าง เพื่อสร้างแท็บใหม่ และตั้งชื่อแท็บเป็นชื่อของตนเอง (เช่น `นพ.ฮัมดี`, `พญ.มูนา`)
3. คลิกแท็บต้นแบบ `Sheet1` แล้วกด `Ctrl+A` (Mac: `Cmd+A`) เพื่อเลือกทั้งแผ่น แล้วกดคัดลอก (`Ctrl+C` / `Cmd+C`)
4. กลับมาที่แท็บใหม่ของตนเอง คลิกเซลล์ `A1` แล้วกดวาง (`Ctrl+V` / `Cmd+V`) เพื่อดึงโครงสร้างและสูตรคำนวณทั้งหมด
5. แก้ไขแถวที่ 3 ให้เป็นชื่อ-สกุล และตำแหน่งของตนเอง

### การบันทึกและส่งข้อมูลรายวัน / สิ้นเดือน (แบบไม่ใช้ Apps Script)
1. เปิดเว็บแอป P4P แล้วกรอกข้อมูลกิจกรรมในแท็บ **"บันทึกรายวัน"** หรือ **"ตาราง 31 วัน"**
2. เมื่อต้องการส่งข้อมูลเข้าชีต ให้ไปที่แท็บ **"ส่งออกข้อมูล"**
3. กดปุ่ม **"คัดลอกข้อมูลวันที่ 1–31 (G6:AK25)"**
4. สลับไปที่ Google Sheet ในแท็บของตนเอง
5. คลิกที่เซลล์ **G6** แล้วกดวาง (`Ctrl+V` / `Cmd+V`) ข้อมูลจะลงตรงช่องทุกวันและคำนวณแต้มให้อัตโนมัติ
